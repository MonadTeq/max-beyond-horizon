# Модель состояния (черновик спецификации)

> Статус: СКЕЛЕТ. Заполняется из RE2.4 (`max-original-dasm/structures.md`) —
> раскладки структур оригинала, сверенные с заголовками C++-порта, и из
> снапшотов headless-сервера.

## 1. Назначение

Описывает состояние партии, которое сервер держит авторитетно и которое
зеркалится в Rust-крейте `max_core` (чистая модель без I/O).

## 2. Каркас (имена — по C++-порту, уточняются в RE2.4)

| Структура | Назначение | Поля (каркас) |
|---|---|---|
| TeamInfo | игрок/команда | id, цвет, ресурсы, победа/поражение, team_type |
| UnitInfo | юнит | id, тип, позиция, hp, ammo, приказы, принадлежность |
| GameManager | глобальное состояние | карта, список юнитов/команд, ход, фаза, RNG-чекпоинты |
| Map | поле | размер, тайлы, ресурсы, туман войны |
| Order | приказ юниту | тип (move/attack/build/…), цель, параметры |

## 3. Снапшот

Полный снапшот = сериализованный GameManager + таблицы TeamInfo/UnitInfo +
счётчик кадров/ходов + RNG-чекпоинт (для сверки расхождений).

## 4. События-дельты

- юнит создан/уничтожен/изменён; приказ принят/исполнен; ход передан; ресурсы
  изменились; конец партии.

> Заполнить: точные поля и кодирование — из C++-заголовков (`src/`), сверенных
> с байтами оригинала (RE2.4), и из сериализации headless-сервера.
