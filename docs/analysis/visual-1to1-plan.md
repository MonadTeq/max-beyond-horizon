## Критерий «визуал 1:1»

- Все элементы оригинального UI/карты доступны и ведут себя как в C++-порте.
- Golden-набор покрывает каждый экран; дрейф = 0 (порог 1 %).
- Живой оконный прогон (мышь) подтверждает ключевые сценарии: высадка, стройка
  (призрак → площадка → строитель → завершение по игроку), меню юнита, End Turn,
  Preferences, x-fer, allocate, research.
