# 04 — Hot-seat (TC-04xx)

2–4 человека на одном компьютере.

| ID | Название | Шаги | Ожидание | Автоматизация |
|---|---|---|---|---|
| TC-0401 | Вход | Multiplayer → Hot Seat Game | Hot Seat Menu (заголовок «Hot Seat Menu») | ✅ QA hs-2.qa |
| TC-0402 | Настройка hot-seat | Players: 2+ Human | заголовок Hot Seat, флаги не переносятся, Done требует 2 человек | ✅ UNIT hot_seat |
| TC-0403 | Окно перехода хода | старт партии 2 человек | модальное окно «Red Team:\nBegin turn.» (HELPFRAM+HELPOK 1:1); закрытие кликом/Enter | ✅ QA hs-2.qa; golden |
| TC-0404 | Чередование команд | 2 человека, несколько раундов | RED→GREEN→RED…; player_team переключается | ✅ QA hs-2 (3 раунда) |
| TC-0405 | 4 человека | 4 Human | RED→GREEN→BLUE→GRAY по кругу | ✅ UNIT |
| TC-0406 | ИИ между людьми | Human, Computer, Human | ИИ ходит сам, окно перехода перед каждым человеком | ✅ UNIT |
| TC-0407 | Изоляция команд | на ходу RED клик по юниту GREEN | чужой юнит не выделяется, приказы не даются | ✅ UNIT |
| TC-0408 | Сброс выделения | передача хода | выделение/предпросмотр сбрасываются | ✅ UNIT |
| TC-0409 | Таймер на каждого | таймер хода | для каждого человека отдельный отсчёт | ✅ UNIT |
| TC-0410 | Hot-seat всегда пошагово | настроить Simultaneous | принудительный turn-based при >1 человек (как C++) | ✅ UNIT |
| TC-0411 | Победа hot-seat | довести до конца | экран победы с местами всех людей | 🟡 (аналог TC-0313) |
| TC-0412 | Load Hot Seat Game / Hot Seat Scenarios | клик | функциональность или честный статус-заглушка | 🟡 заглушка |
