# Анализ: реверс-инжиниринг оригинала (указатель)

Реверс-инжиниринг оригинальной `MAXRUN.EXE` (DOS/4GW, Watcom) ведётся в
каталоге `max-original-dasm/` как вспомогательная линия: основной источник
истины для порта — C++-код `max-cpp-port/`, RE используется для верификации
и пробелов.

## Ключевые установленные факты

- Формат: MZ + DOS/32A v9.1.2 (bound) + LE; объекты 1-базовые (#1 код 0x10000,
  #2 ISR COM2, #3 данные 0x150000).
- Статический вход игры: **0x10C704**; рантайм (под DOSBox-X): obj#1 по базе
  0x170010, вход **0x26C714** (`runtime = static + 0x160010`), main() = 0x20884E.
- Розеттский камень: 18 372 строки бинаря, 2583 сопоставлены с файлами C++.
- Каталог функций (radare2 + LE-fixups): 6857 функций, 159 с именами C++.
