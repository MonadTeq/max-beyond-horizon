# Системный классификатор объектов игры

Каноническая таксономия игровых объектов (DSL). Ведётся аналитиком; соответствует
`domain-map.md` (таблица «домен-термин → Rust-имя → C++-идентификатор»).

## Юниты

```
Юнит (Unit)
├── Боевой (Combat)          — здание ИЛИ мобильный
│   ├── Боевое здание        — стационарные пушки:
│   │                          пушка / ракетомёт / зенитка / артиллерийская установка
│   └── Боевой мобильный     — воздушный / наземный / парящий
└── Небоевой (Non-combat)    — здание ИЛИ мобильный
    ├── Небоевое здание      — производящее / непроизводящее
    └── Небоевой мобильный   — воздушный / наземный / парящий
```

### Оси классификации юнитов

| Ось | Значения | Rust-имя (маркер/признак) | C++ |
|---|---|---|---|
| Боевая роль (верхний уровень) | Боевой / Небоевой | `Combat` / `NonCombat` | — |
| Форма | Здание / Мобильный | `Building` / `Mobile` | `STATIONARY` / `MOBILE_*` |
| Среда мобильного | Воздушный / Наземный / Парящий | `Air` / `Ground` / `Hovering` | `MOBILE_AIR_UNIT` / `MOBILE_LAND_UNIT` / `HOVERING` |
| Производство (небоевые здания) | Производящее / Непроизводящее | `Producing` / `NonProducing` | — (по признаку завода) |

## Эффекты (не юниты)

```
Эффект (Effect) — НЕ юнит, отдельный класс
├── Снаряд (Projectile)
├── Взрыв (Explosion)
├── Обломок (Rubble)
└── След (Trail)
```

Эффекты логически не входят в классификатор юнитов (смешение — нарушение слоёв).
Текущее совмещение эффектов с `UnitType` (93 типа) — технический долг, устраняется
по правилу 2 программиста.

## Примечания

- Термины «Боевой/Небоевой», «Здание/Мобильный», «Воздушный/Наземный/Парящий»,
  «Производящее/Непроизводящее», «Эффект» и его подклассы — канонический DSL.
- Соответствие конкретных типов юнитов (93) классам ведётся в `domain-map.md`.
