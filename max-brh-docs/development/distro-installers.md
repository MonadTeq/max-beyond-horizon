# Дистрибутивы и графические установщики — план

Версия 0.1 (Архитектор) · 2026-11-28. Идея: ремейк устанавливается БЕЗ оригинальной игры (standalone), ресурсы в HD.

**Корень проекта инсталлятора: `max-brh-installer/`** (решение владельца 2026-11-28) — ресурсы установщика (иконки, баннеры, рамки UI) и скрипты NSIS/пакетирования живут там.

## Часть A. Инвентарь рантайм-зависимостей (по коду загрузчиков)

**Обязательный минимум:** `MAX.RES` (1828 записей, 17 МБ; входит в `data_hash` сети), `PATCHES.RES` (дескрипторы миссий/`SC_UNITS`), `COLOR.PAL`, карты `.WRL` (24, 28 МБ).

**Условно-обязательные:** звуки `*.SPW` (272, 24.5 МБ), портреты `*.FLC` (71, 9.5 МБ), видео `*.MVE` (3, 95.5 МБ), музыка `*.MSC` (13/16, 181.7 МБ; `BKG7/8/9` нет в GOG-копии — пропускаются штатно), миссии кампании (~11 МБ), `maxint.json` (субтитры).

**Вшито в бинарь:** шрифты FONT1/2/5, language/help/credits/юнит-таблицы.

**Не читается (исключить):** DOS-файлы, DOSBOX, `*.gog`, `MAX.INI`, MANUAL.PDF, SETUP.EXE и пр. (~12 МБ мусора из 378).

## Часть B. Раскладка — ПОРТАТИВНАЯ (решение владельца 2026-11-28)

**Один каталог игры, выбранный пользователем; ВСЁ берётся оттуда и сохраняется туда. Установщики НЕ раскладывают ничего по системным каталогам (%APPDATA%/$XDG/Program Files/usr не используются).**

```
<install-dir>/                        ← выбранный каталог, пишется
  game.exe, SDL3.dll                 (Windows; бинарь переименован из max-brh.exe)
  max-brh, lib/libSDL3.so*           (Linux)
  data/   MAX.RES, PATCHES.RES, COLOR.PAL, *.WRL, *.SPW, *.FLC, *.MSC, *.MVE,
          миссии, maxint.json
  remaster/  *.ktx2 + remaster-manifest.json   ← ОБЯЗАТЕЛЬНАЯ часть (ключевой смысл проекта)
  saves/  missions/  preferences.ini  settings.jsonc      ← данные игры ТУТ ЖЕ
  LICENSE, THIRD_PARTY_LICENSES.*, README.txt, CHANGELOG.md
  uninstall.exe (Windows)
```

- Текущий код уже сохраняет «рядом с MAX.RES» (родитель каталога данных) — для портативной раскладки работает как есть; кодовые правки этапа 2 минимальны: маркер данных `["max-original","data"]` и приоритет `settings.jsonc` (CLI → каталог игры → встроенный дефолт). Per-user дефолты (B4) НЕ нужны.

## Часть D. Установщики (портативные, без системной установки)

- **Windows — NSIS 3.x (MUI2)**: мастер «выбрать каталог → компоненты → установить»; ВСЁ внутрь каталога; **без** записи в реестр ARP; **ярлык в меню Пуск — опциональный чекбокс**; uninstall.exe внутри каталога; тихий режим `/S /D=каталог`. Бинарь в пакете — **game.exe**.
- **Linux — переносимый tar.gz** (каталог целиком) + **AppImage (нужен в v1)**: данные и remaster внутри; сейвы рядом с AppImage.
- **Remaster — обязательная часть обоих пакетов** (не отдельный опциональный пакет).

## Часть E. Лицензии/распространение — решения владельца (2026-11-28)

- **D1**: бесплатный некоммерческий фан-ремейк (владелец), без платформ; риск ассетов Interplay — осознанный (зафиксировано владельцем).
- **D7**: только прямое распространение (собственный сайт/ссылки); Steam/GOG/итп — нет.

## Часть F. Этапы и гейты (пересмотрено под портативную модель)

| Этап | Содержание | Гейт |
|---|---|---|
| 1 | `asset_inventory` → `data-inventory.json` (sha256) | G1: манифест точный, детерминизм, оракулы чисты |
| 2 | Портативная структура (маркер `data`, `settings.jsonc` приоритет) | G2: smoke — игра из выбранного каталога читает/пишет всё ВНУТРИ него; staging-макет 0 нехваток |
| 3 | NSIS-портативный установщик (каталог → всё внутрь, uninstall.exe) | G3: тихая установка в выбранный каталог, деинсталляция чистит ТОЛЬКО каталог, сейвы внутри переживают апгрейд |
| 4 | Linux tar.gz (переносимый) + опционально AppImage | G4: распаковал → запустил → сейвы в каталоге игры; AppImage запускается |
| 5 | CI `release.yml` по тегу v* (Windows zip+NSIS, Linux tar.gz/AppImage, SHA256SUMS) | G5: все гейты зелёные, артефакты опубликованы |

## Guardrails

Оракулы read-only; данные в пакете байт-в-байт = оракулы; HD/remaster строго обязателен и аддитивен; **всё рантайм-записываемое — только внутри каталога игры**; детерминизм сборки; **версия — пре-альфа `0.1.28a` (единый источник: workspace Cargo.toml; до 1.0 не поднимать — решение владельца)**.

1. Лицензия данных — зафиксировано владельцем (бесплатный фан-ремейк, осознанный риск). 2. Медиа 277 МБ — возможен опциональный компонент «Music/Videos». 3. Портативность: не писать абсолютные пути в настройках/сейвах.
