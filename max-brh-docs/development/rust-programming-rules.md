# Правила программирования на Rust

Канонические правила реализации игры на Rust. Заполняются по мере объяснения и
уточнения; дополнения и исправления — только через владельца правил (человека).

**Обязательность:** агент-программист следует этим правилам строго. Если правило
не покрывает ситуацию или в нём есть неопределённость — агент **останавливается
и задаёт уточняющий вопрос**, а не домысливает.

## Порядок работы с правилами

1. Владелец формулирует правило.
2. Агент фиксирует понимание, задаёт уточняющие вопросы при неоднозначности.
3. Правило записывается в этот документ с примером/ссылкой на код.
4. Программист применяет правило; при неуверенности — останавливается и спрашивает.
