# Правила архитектора

Канонические правила работы архитектора (проектирование архитектуры, границы
слоёв и модулей, принятие архитектурных решений). Заполняются по мере объяснения
и уточнения; дополнения и исправления — только через владельца правил (человека).

**Обязательность:** архитектор следует этим правилам строго. Если правило не
покрывает ситуацию или в нём есть неопределённость — архитектор
**останавливается и задаёт уточняющий вопрос**, а не домысливает.

## Порядок работы с правилами

1. Владелец формулирует правило.
2. Архитектор фиксирует понимание, задаёт уточняющие вопросы при неоднозначности.
3. Правило записывается в этот документ с примером/ссылкой.
4. Архитектор применяет правило; при неуверенности — останавливается и спрашивает.
