# Чек-лист ручного прогона 1.2/1.3 (пре-альфа)

Цель: пройти партии вручную и собрать дефекты. Запуск — `max-brh.exe` (GUI,
окно SDL3) из `max-brh/target/release/`. Данные игры — `--data-dir max-original`
(по умолчанию подхватывает `MAX.RES`/`PATCHES.RES`).

## Запуск

```
max-brh.exe                          # GUI: меню → партия
max-brh.exe --data-dir D:\dev\max-port-debug\max-original
max-brh.exe --scale 2                # крупнее окно (по вкусу)
max-brh.exe --fps                    # бюджет кадра в заголовке
```

## 1.2 Одиночная игра против ИИ (1–3 ИИ)

Для каждого состава (1 ИИ, 2 ИИ, 3 ИИ) и двух планет (Snow/Red+Green):

1. **New Game → Options** (планета, сложность ИИ, условия победы) → **Players**
   (RED человек, GREEN/BLUE/GRAY компьютер).
2. **Мобилизация**: купить юнитов, Done. **Высадка**: точка, Done.
3. **Партия** до победы/поражения:
   - ход человека: стройка, производство, перемещение, бой, атака;
   - ход ИИ: ИИ строит базу, производит армию, атакует, разведывает, исследует;
   - End Turn: корректное переключение, окно «Begin turn».
4. **Критерий**: партия до экрана победы/поражения без паник/зависаний/десинков.

## 1.2.1 Поведение ИИ (что проверить)

- ИИ **строит** (шахта/склад/завод/генератор/радар) по стратегии;
- ИИ **производит** армию/флот (не только стартовые юниты);
- ИИ **атакует** (накапливает резерв, штурмует при видимости);
- ИИ **исследует**/апгрейдит (тратит золото);
- ИИ **разведывает** (TaskExplore, скауты).

## 1.3 Hot Seat (2–4 человека)

1. **New Game → Hot Seat** → 2–4 команды-человека.
2. Чередование ходов: окно «Begin turn» для каждой команды, корректный
   переключатель, таймер хода.
3. Полная партия до победы/поражения.

## 1.3.1 Hot Seat + ИИ (смесь)

- 2–4 команды: часть человек, часть ИИ.
- Чередование человек ↔ ИИ: блокировка ввода на ходу ИИ, имена команд.

## Что сообщать (дефект)

- **Шаги воспроизведения** (меню → действие → что увидели);
- **Ожидание vs факт** (что должно быть по M.A.X., что произошло);
- паники/зависания/десинки/визуальные баги — с описанием экрана;
- при падении — `--fps`-лог и (если есть) `qa-out`/`build`-артефакты.
