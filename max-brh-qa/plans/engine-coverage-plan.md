## 1. Принципы доказательства

Для каждой механики — три уровня, все обязательны:

| Уровень | Что доказывает | Инструмент |
|---|---|---|
| **U — юнит** | чистая функция/структура: границы (0, MAX, ошибка), инварианты | `#[cfg(test)]` в `src/*.rs` |
| **I — интеграция** | сценарий на `GameState`: «дано → приказы → тики → ожидаемое состояние» | `max_core/tests/*.rs` |
| **D — детерминизм** | бит-в-бит с оракулом/эталоном | CRC16, `replay_digest_bytes`, `state_checksum`, V70 байт-в-байт |

Оракул (правило 3 AGENTS.md): Interplay → Klei → человек. Ожидаемые значения —
из `max-cpp-port` (структура/имена) и `max-original`+`max-original-dasm`
(истина); спорное — эскалация.

## 3. Фазы (по риску → редкости)

**Фаза 1 — ядро-критика (state machine + экономика).** `game.rs`, `setup.rs`,
`deploy.rs`, `victory.rs`, `events.rs` — сейчас тонко, а это скелет партии.
Цель: интеграционные сценарии «создание → фазы → тики → победа/поражение».

**Фаза 2 — юниты/бой.** `unit.rs`, `combat.rs`, `unit_order.rs`, `order.rs`,
`pathfinding.rs`, `frames.rs` — все order-переходы, все типы оружия, обход
препятствий, цикл анимации.

**Фаза 3 — экономика/ресурсы.** `complex.rs`, `alloc.rs`, `power.rs`,
`transfer.rs`, `production.rs`, `research.rs` — полный граф комплексов,
доли добычи, профицит/дефицит, все стоимости.

**Фаза 4 — сохранение/детерминизм.** `save.rs`, `save_write.rs`, `crc.rs`,
`rng.rs`, `hash.rs`, `access.rs`, `classification.rs`, `unit_values.rs`,
`team.rs` — V70 байт-в-байт (все поля, битые файлы), CRC/снапшот по эталону.

**Фаза 5 — ИИ-интеграция.** Каждая ИИ-область — сценарий «класть: база +
противник → N ходов → ожидаемые задачи/юниты/CRC». Закрепить порт A.

## 4. Инструменты и регресс

- Все тесты — `cargo test -p max_core --no-default-features` (нативно MSVC).
- Детерминизм: `p7` (`mini_replay_matches_cpp_digest_bit_for_bit`,
  `network_crc_matches_cpp_vector_bytes`) — регресс-барьер, НЕ трогать.
- Для фаз 1–5 — новые интеграционные файлы `max_core/tests/<mech>.rs`; юниты —
  в `src/<модуль>.rs`.
- AI CRC зафиксирован в `analysis/ai-port-status.md`; при изменении ИИ —
  обновлять таблицу там же.

## 5. Метрика готовности (гейт ручного прогона)

- Матрица §2: нет ❌; все «🟡 целевое» закрыты U+I+D.
- `cargo test -p max_core --no-default-features -q` — зелёный.
- `p7` и golden-дайджест — без регрессий.
- Каждый закрытый модуль имеет минимум: 1 юнит на инвариант, 1 интеграцию на
  сценарий, 1 CRC/снапшот на детерминизм.
